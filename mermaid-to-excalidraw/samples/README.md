# Mermaid conversion samples

These documents are conversion fixtures for `/mermaid-to-excalidraw`. Each
diagram family has its own Markdown file, with multiple fenced Mermaid blocks
to exercise common shapes, labels, connectors, annotations, and layouts.

The syntax catalog follows the Mermaid documentation in the repository's
`packages/mermaid/src/docs/syntax` directory. Experimental and beta diagram
types are included as such; they may require a recent Mermaid release.
